## 1. North Carolina vs TCU — Dublin · Sat noon ET · ESPN

**What decides it**
- UNC rush offense #127 vs TCU rush defense #28 — the run game is closed
- UNC's path: Edwards at TCU's #103 pass defense
- TCU pass offense #29 vs UNC pass defense #49 — best-on-best
- Structural disagreement: the moneyline says TCU ~73%, the machine says 54%

**Keys — North Carolina**
1. Throw it — TCU's pass defense is the soft spot; the run game is closed
2. Win the hidden yards — the special-teams edge is real (#31 vs #84)
3. Bend-don't-break without Steve Belichick: keep the defense simple
4. Keep the circus outside: a clean, scripted first quarter

**Keys — TCU**
1. Craig efficient, not heroic — distribute to a loaded receiver room
2. Make UNC one-dimensional with the run front, then rush the passer
3. Hold up in the back end with a new starting safety (Fields dismissed)
4. Dwyer in the return game: the weapon inside a mediocre unit

**Score prediction: TCU 25 – UNC 23.** Machine TCU −1.5 (fair TCU −118 /
UNC +118); market TCU −7.5 / −8 (ML −310). Coin-flip-plus for the machine, a
three-to-one favorite for the market — the market is pricing UNC's chaos.
Research, not a play.
